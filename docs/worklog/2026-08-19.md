## Tailwind build (replaces pre-built CSS)
- The repo shipped a 93 KB pre-built `markiverse.css` with no Tailwind build,
  so any new utility class silently did nothing. Replaced with a real
  Tailwind v4 pipeline: `tailwindcss` + `@tailwindcss/postcss` +
  `tw-animate-css`, `postcss.config.mjs`, and `src/app/globals.css` as the
  single source (tokens in `@theme`, `:root` values, base, custom utilities,
  keyframes). `custom.css` folded in and removed. Compiled CSS ~48 KB.

## Design tokens / reskin readiness
- Every colour, gradient, shadow and font resolves to a `:root` token; the
  last hard-coded values in components were replaced (`--success`,
  `--ink-shadow`, named `drop-shadow-lift/-sm/-float`, `color-scheme`).
- Reskin = edit `:root`; dark mode = add a `.dark {}` block (variant wired).

## Themes

- `ThemePicker` in the header (palette button → swatch list), persisted in
